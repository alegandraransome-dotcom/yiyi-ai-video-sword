# 以一 V2.0 Beta-3｜工业兼并迁移总账
## ACTING / CINEDANCE / LIRA｜第二轮完整吸收审计

> 版本定位：**V2.0 Beta-3**。不是V2.01，不是Final。
>
> 本账本的用途不是证明“文件变短了”，而是证明外部Skill里的有效能力有明确去向。每条能力只允许：`KEEP / MERGED / ADAPTED / MOVED TO 10 / REJECTED AS HARD RULE / DEFERRED FOR TEST`。禁止“看起来重复，所以静默删掉”。

# 0｜本轮方法

本轮重新完整读取：
- ACTING SYSTEM（全文件）；
- CINEDANCE V4（全文件）；
- LIRA Image Prompt Optimization（全文件）；
- 以一 V2.0 Beta-2母版。

吸收标准：
1. 先找外部Skill真正解决的生产问题；
2. 再判断以一是否已经有同职责能力；
3. 已有但更弱 → 升级；
4. 已有且同强 → 合并/保留；
5. 平台专用 → 移入低频10 Adapter，不塞进导演核心；
6. 与以一导演自由冲突的教条 → 保留启发价值，但拒绝成为硬规则。
