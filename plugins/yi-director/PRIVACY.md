# 以一导演隐私政策

生效日期：2026-08-20

本政策适用于由怕冷的阿钰发布的 `yi-director` 纯 Skills 插件及其官方直接上传版。

## 插件本身的数据处理

本产品只包含随发布包分发的文字说明、参考资料和图标，不包含 MCP 服务器、发布者自有后端、登录系统、遥测、广告或分析代码。本产品运行时不会把用户的提示词、剧本、图片、视频、生成结果、账号信息或设备信息发送给怕冷的阿钰；怕冷的阿钰也不会通过本产品收集、出售或留存这些数据。

因此，对于插件本身：

- 收集的数据类别：无；
- 使用目的：无；
- 数据接收方：无；
- 发布者留存期限：无；
- 用户控制：可随时禁用或卸载插件。

## ChatGPT、OpenAI 与用户选择的工具

用户需要通过 ChatGPT、Codex 或其他兼容宿主使用本产品。用户在对话中提交的文字和附件，以及宿主为完成任务而生成的内容，会由 OpenAI 或相应宿主按其适用条款与隐私政策处理。如果用户主动选择其他图像、视频或文件工具，相应提供者的政策也可能适用。怕冷的阿钰不控制这些第三方的数据处理。

## GitHub 支持

如用户通过公开 GitHub Issue 寻求支持，Issue 内容、GitHub 用户名及用户主动提供的信息会由 GitHub 处理，并可能被仓库维护者、公众访问者、搜索引擎和缓存或存档服务看到。该信息只用于处理支持、安全或兼容性问题，通常会随 Issue 保留。即使原 Issue 被编辑或删除，其副本仍可能存在于 GitHub 通知、备份或第三方缓存中，怕冷的阿钰无法保证完全删除。请勿在公开 Issue 中提交未公开剧本、个人身份信息、账号凭据或其他敏感内容。

用户可以在对应 Issue 中提出最小化的编辑或删除请求，不要在请求中重复敏感内容。维护者会在其控制范围内处理公开仓库内容；GitHub 自身的数据处理适用 GitHub 的政策。

## 政策变更

若插件未来增加发布者服务器、账号、遥测或其他数据处理能力，本政策会在启用相关能力前更新，并通过插件版本说明披露。

## 联系方式

隐私或支持问题请通过本仓库的 [GitHub Issues](https://github.com/alegandraransome-dotcom/yiyi-ai-video-sword/issues) 提交，并避免包含敏感信息。
