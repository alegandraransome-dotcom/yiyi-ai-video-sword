# 以一导演插件

`yi-director` 是一个纯 Skills 插件，为 AI 真人短剧提供从剧本筹备到成片返工的导演工作流。

- 插件版本：`0.1.0`
- 知识基线：YI Director Runtime Beta-3，并含叙事光影与平台导出增强
- 外部服务器：无
- 插件自身要求的额外账号或 API Key：无
- GitHub 用途：分发、安装和更新；日常使用不需要持续连接 GitHub

## 能做什么

- 通读剧本，建立人物、场景、道具和站位资产清单。
- 设计人物表演、Blocking、镜头和 9:16 正式分镜。
- 用有来源的光、曝光层级和材质响应设计可连续的叙事光影。
- 输出 15/30 秒 AI 视频段，并按需导出 Seedance/Higgsfield 可直接使用的平台成稿。
- 保持空间、动作、道具、伤势和世界光向连续。
- 针对已有图片或视频进行复看、诊断和局部返工。

插件会调用宿主中用户已经拥有且适合当前任务的文件、图像或视频能力；它本身不附带视频生成额度，也不会自动注册或购买第三方服务。

## 从 GitHub 测试安装

先把本仓库添加为 Marketplace：

```bash
codex plugin marketplace add alegandraransome-dotcom/yiyi-ai-video-sword --ref main
```

然后刷新或重新打开 Skills/Plugins 页面，在目录中选择“以一导演”并安装。仓库版适合测试和定向分发；要让所有 ChatGPT 用户直接从通用插件目录发现，还需要由发布者在 OpenAI Platform 完成身份验证、审核和发布。

## 使用方式

安装后可以直接说：

- “根据我接下来上传的短剧剧本和参考图，先整理人物、场景、道具和站位资产清单。”
- “根据我接下来提供的一场短剧，保持剧情和台词不变，按 9:16、每段 15 秒输出完整电影感分镜。”
- “根据我接下来提供的分镜，检查空间、轴线、人物动作和连续性，并输出修正后的完整版本。”
- “保留现有正式分镜，只重做这一场从可见财富转向隐形权力的光影设计。”
- “把已确认的第3序导出为 Seedance 2.5 可直接复制的最终 Prompt，台词逐字不变。”
