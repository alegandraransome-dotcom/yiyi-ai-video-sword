# 导演光影系统

> 光影不是“电影感”形容词，也不是摄影完成后的美容层。它决定观众先看见什么、暂时看不见什么、人物怎样占有空间，以及一个戏剧变化如何在画面里发生。

## 一｜光影任务

先从戏剧推光，不从灯具名称推戏：

```text
STORY BEAT
→ ATTENTION TARGET
→ MOTIVATED SOURCE MAP
→ SUBJECT / BACKGROUND HIERARCHY
→ EXPOSURE + MATERIAL RESPONSE
→ CONTINUITY / CAUSAL DELTA
→ VISIBLE RESULT
```

每个重要Beat先回答：

- 观众此刻必须最先看见什么？
- 哪些信息应当清楚，哪些只需感觉，哪些应暂时隐藏？
- 光在强化谁的控制、孤立、暴露、误判或失势？
- 这一变化是否能由当前真实光源完成？

不能只把“权力感、压迫感、奢华感”换成“冷暖对比、高级轮廓光、电影级光影”。抽象意图必须落到可见的光源、亮度层级和材质结果。

## 二｜场次光线母版

采用：

```text
PROJECT BASELINE → SCENE LIGHTING RIG → SHOT DELTA
```

场次光线母版只锁会持续影响多个镜头的事实：

- 时间、天气与空间功能；
- 主要实景光源及其世界位置；
- 主导光向、软硬和综合色关系；
- 人物、关键道具与背景的曝光优先级；
- 暗部允许落到什么程度；
- 玻璃、金属、水、黑色织物、皮肤等关键材质如何保留；
- 烟、雨、尘、VFX是否真正受光；
- 哪些灯光状态可发生剧情变化。

基线建立一次。无变化时继承，不逐镜复制；但每个独立生成段必须带上会影响当前生成正确性的主要光向和曝光锚点，不能只写“同上”。

## 三｜世界光源地图

光源先存在于三维世界，再投影到画面。按需为每个重要来源确认：

- 来源：窗、吊灯、壁灯、屏幕、门外走廊、街灯、车灯、月光、火、警报灯等；
- 世界位置与高度；
- 朝向与覆盖区域；
- 光源面积对应的软硬；
- 色温或相对冷暖；
- 衰减、遮挡和反射；
- 它照到谁、照不到谁；
- 人物移动会经过哪些光区。

“侧光、顶光、轮廓光”如果没有来源，只是画面效果，不足以保证连续。不得让主光为了构图跟着摄影机翻到另一边。

没有可信来源时，优先调整人物站位、机位、实景灯或环境反射；不要凭空生成一束只负责让脸变漂亮的光。

## 四｜注意力与曝光层级

亮度不是越高越好。先锁优先级：

1. 当前叙事信息；
2. 人物眼神、手或关键道具中真正承担Beat的部分；
3. 建立空间所需的前中后景；
4. 可以自然落暗或溶解的装饰。

按需要判断：

- 人物哪一侧可读，哪一侧自然落暗；
- 背景是否与脸同亮、抢走注意；
- 窗外城市、白衬衫、屏幕、水晶和金属高光谁优先保留；
- 黑衣、深色墙面和夜景是否仍有层次；
- 暗部是否保留必要眼神和空间边界；
- 是否需要负补光、环境反射或局部控制，而不是全脸美容式填平。

不要为了“夜”把一切压死，也不要为了“看清”把所有面照成同一亮度。

## 五｜人物和材质响应

### 人脸与眼睛

- 肤色优先自然，不因湿地、霓虹或水面反光自动变成油亮塑料皮；
- 眼神承担剧情时保证可读，但不强制每个镜头出现明亮catchlight；
- 特写越近，越要控制额头、鼻梁、面颊高光和眼白，不靠磨皮解决曝光；
- 强者不必永远藏在暗处，弱者也不必永远被顶光压迫，服从人物和Beat。

### 常见材质

- **黑色西装 / 深色织物**：保留织物、翻领和身体轮廓，不能死成一块黑洞；
- **水晶 / 玻璃**：保留边缘、折射和少量高光，不让整片爆白；
- **金属**：反射应对应真实光源和表面方向，不生成均匀白边；
- **水 / 湿地**：反射随观看角度与光源变化；湿衣可亮，皮肤仍按人物质感控制；
- **烟 / 雾 / 尘**：只有位于光路中才显形，不把体积光当默认高级感；
- **木、石、皮革**：用表面粗糙度、使用痕迹和局部反射区分，不靠全局锐化。

## 六｜摄影机、调度与连续性

光影必须与摄影机和Blocking一起设计：

- 摄影机位于人物受光侧还是阴影侧？这个选择带来什么观看结果？
- 人物靠近、后退、转身、穿门时，会进入或离开哪一个真实光区？
- 摄影机移动时，光源仍固定在世界里；变化来自视角、遮挡、距离和反射，而不是灯光瞬移；
- 正反打切换后，画面左右可以改变，世界光向不能无原因翻转；
- 内部多镜头和独立生成段继承实景灯开关、综合色、主光方向和曝光层级；
- 前景遮挡光源、人物挡光、门开启漏光等事件必须产生符合因果的画面反馈。

反打若需要更好地读脸，可使用同一世界中可信的环境反射或局部补光；不能把另一侧的主光复制过去冒充连续。

## 七｜光影叙事变化

光影变化使用：

```text
TRIGGER → DEVELOPMENT → SUBJECT / SPACE RESPONSE → NEW STABLE STATE
```

有效触发包括：门打开、人物穿越光区、屏幕点亮、车灯扫过、警报灯启动、火焰扩大、太阳被云遮挡、灯具被破坏。

无效做法：人物说到关键台词时，环境主光无来源地自动变暗；坏人出现时，随机新增彩色轮廓光；情绪升级时，所有高光一起闪烁。

一场戏可以有光影弧线。例如：

```text
被展示的暖亮财富
→ 后台暖光衰减、冷白工作光接管
→ 私人金融空间减少环境填充
→ 文件、手与局部桌面最清楚，掌权者仍未完全显形
```

这里的冷暖与明暗不是装饰，而是在完成“可见财富 → 隐形权力”的叙事。

## 八｜正式分镜与平台语言

正式分镜仍把光影写进`【摄影】`，不增加逐镜第四栏目。

当一个段包含多镜且光线母版承担叙事，可在段头按需加入一次：

```text
【光影基线】主要来源、世界光向、人物/背景层级、曝光优先和本段变化边界。
```

后续每镜只写Delta。自然顺序：

```text
CAMERA / OPTICS
→ COMPOSITION
→ SOURCE + HIERARCHY + EXPOSURE
→ MATERIAL / ATMOSPHERE RESPONSE
→ CAMERA OR LIGHTING CHANGE
```

平台提示词不复制灯光教科书。把已完成判断压成少量高信号可见语言：来源在哪里、人物哪一侧可读、什么高光必须保住、背景压到哪里、变化由什么触发。

## 九｜常见失败与修复

1. **Prestige Soup**：只有“高级、电影级、冷暖对比” → 写真实来源、位置、层级和可见结果。
2. **Beauty Fill**：所有脸均匀发亮 → 恢复人物与背景的明暗关系，允许一侧自然落暗。
3. **Teleporting Key**：切反打后主光跟画面翻边 → 回世界光源地图重投影。
4. **Random Rim**：每个人都有无来源彩边 → 删除装饰轮廓光，回到实景来源。
5. **Dead Blacks**：黑衣与夜景糊成一块 → 保留材质分离和必要暗部层级，不简单整体提亮。
6. **Clipped Wealth**：水晶、金属、白衬衫全爆 → 重排曝光优先，控制高光而非磨平材质。
7. **Plastic Skin**：环境反射爬满人脸 → 分开皮肤与湿地/玻璃的响应，恢复哑光毛孔。
8. **Global Tint**：全画面被同一蓝/橙覆盖 → 让颜色属于真实来源和不同空间层级。
9. **Causeless Flicker**：灯光随情绪随机闪 → 找真实触发，否则保持稳定。
10. **Flat Background**：人物与背景同亮同色 → 用亮度、综合色、遮挡或空气透视恢复层级。

## 十｜隐藏验光门

交付前内部确认：

1. 当前光影是否完成了这一Beat的观看任务？
2. 主要光源是否存在于同一个三维空间？
3. 人物、关键道具和背景的曝光优先是否清楚？
4. 皮肤、黑衣、玻璃、金属、水和空气是否各自像真实材质？
5. 摄影机移动、正反打和跨段后，光向与灯光状态是否连续？
6. 光影变化是否有触发、发展和稳定结果？
7. 正式稿是否只写当前真正可见的控制，而非形容词堆积？
8. 若用户只要求局部调暗/调亮，是否保持原光源、空间、构图和人物不被重设计？

不输出“已通过光影检查”。直接修到成立后交付。
