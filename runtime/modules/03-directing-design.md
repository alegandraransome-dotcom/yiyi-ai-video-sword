# 03｜导演设计
## 以一 V2.0｜Directing Design

> 本文件解决：“真正怎么把戏导演成电影。”它不是正式分镜格式文件；正式写法由05负责。

# 一｜输入与运行

优先读取Director Brief、当前Canon、当前状态、当前资产、项目视觉/摄影/光影/声音基线、WEI-K / Protected Values。Brief里已LOCKED的事实不得在此偷偷改写。

```text
WEI PREVIEW → HENG DIRECT → WEI DIRECTOR REVIEW → HENG LOCK → DIRECTOR BLUEPRINT
```

Blueprint已LOCKED时，正式制作只恢复，不重跑完整创作循环；只有受影响分支被重新打开时才重设计。

# D1｜戏剧与信息

明确：戏剧轴、主动权、权力/情绪转移、观众此刻知道什么、接下来期待什么、哪个信息必须看懂、哪个只需感觉、哪个反应比事件本身更重要。

镜头不是剧本动作句子的录像。

# D2｜观看入口与场景建立

新场景不强制大全景。场景建立只需让观众及时获得当前戏真正需要的人物位置、关系、空间、气氛、异常、叙事焦点。

可从环境、人物局部、声音、运动、物件、结果进入。选择最有观看价值的入口，不套模板。

# D3｜人物表演与场面调度

## 核心公理：表演是压力下的行为

人物不是“展示情绪”，而是在某种阻碍和代价下，试图从别人 / 世界那里得到什么。情绪是争取、失败、掩饰和改变策略的结果。

内部优先理解：

```text
OBJECTIVE
→ OBSTACLE + STAKES
→ TACTIC
→ STIMULUS
→ REACTION
→ CHOICE
→ ACTION
→ PARTNER RESPONSE
→ TACTIC CHANGE / BEAT CHANGE
```

原有 `STIMULUS → REACTION → CHOICE → ACTION` 保留，但不再悬空：它被放回人物目标和策略之中。

### Objective / Tactic
- Objective尽量是指向具体对象的动作性欲望；
- Tactic是人物当下采取的办法；
- 一个策略长期不变，表演容易变平；
- 新信息、策略失败、权力变化会触发Beat Change。

### Listening / Assessment
- 真正的反应可以在对方一句话还没说完时就开始；
- 困难回答前允许“想法先出现、话后出来”；
- 重要新闻、威胁、羞辱、异常必须有Assessment Moment，时长按戏决定；
- 停顿只有内部发生了判断、选择、拒绝或Business变化时才成立；空停顿就剪掉。

### Subtext
潜台词不是第二套台词，不要要求演员“演潜台词”。人物追求真实Objective，而嘴上可能掩饰、回避、撒谎、转移，潜台词从失败的遮掩里漏出来。

### Physical Life
每个重要Beat按需判断：
- 重心；
- 动作Tempo；
- 身体开放 / 封闭；
- 呼吸；
- 眼神与Blink / Gaze Target；
- 手；
- Business；
- 与物体 / 对方距离；
- Status；
- 面具何时裂开。

**Business不是强制给每个人塞动作。** 如果人物本来就在做事，让动作真实存在；如果没有自然Business，不为“显得会演”制造无意义手部任务。Business被突然停止时，可以成为很强的戏剧标点。

### Proxemics / Status
距离变化本身可以是剧情：谁靠近、谁后退、谁停住、谁侵入别人空间。Status通过身体和节奏体现，不只靠台词；最有价值的往往是短暂的Status Break。

“强者更静、弱者更躁”可以作为某些类型片的状态工具，但**不是普遍铁律**，不能覆盖角色设定和项目风格。

### Eye Life
眼睛要像在思考而不是冻结：目光先到目标，头再跟；需要时有微小扫视、眨眼、重新聚焦。特写越近，动作通常越少，让思想而不是表情堆砌承担表演。

Blocking来自欲望、风险、关系、权力和空间功能，不为了构图随意让人物走位。

对白不是“说话者特写自动覆盖”。恒要判断谁拥有画面、听者何时更重要、是否让对白画外继续、是否重叠/打断/停顿、语言与身体行为是否一致。原台词文字与含义未经许可不改；真实感主要来自交付方式、节奏、重叠、呼吸和反应，而不是擅自把台词改得更口语。

> 先调度后机位，但二者可迭代；机位不得用来掩盖不存在的调度，调度也不得为炫技运镜服务。


## D3-A｜复杂人物、群体与动作动机

### Two Truths / Paradox
关键人物尤其在近景 / 特写里，不强迫只存在一个“纯情绪”。当剧本支持时，可以让两条真实同时成立；恒把它们落实为策略、身体和节奏的拉扯，而不是写成解释性心理旁白。

### Movement = Motivation
人物跨房间、靠近、退开、起身、坐下、转背、停在门口，都应该有当前动机或空间功能。不要因为构图空了就让演员无意义走两步。

### Ensemble Reaction Wave
群体事件后优先设计“反应波”而非同拍同步：第一人先看见，第二人被第一人带动，第三人反应更弱或更迟。群演的强度、方向和延迟按身份与可见性分层。

### Threat Without Wind-up｜按类型使用
危险人物不必总先眯眼、慢转头、停顿、做“我要危险了”的预告动作。若类型和人物允许，暴力 / 威胁可以从日常行为直接发生；真正的危险感也可以来自周围人突然收声、停手、让路。它是工具，不是“强者永远安静”的铁律。

### State Inertia
重大情绪 / 身体事件后，下一Beat不是自动归零。残留可能进入呼吸、步态、视线稳定度、语速、握力、坐姿、受伤保护动作；延续多久由剧情和人物决定。

### Speech Delivery｜不改原台词
在不改原台词文字 / 含义的前提下，可导演：
- 对方句尾未落，听者已产生细反应；
- 合理的Overlap / 打断；
- 关键字保持清楚；
- 压力下音量可能反而降低；
- 停顿必须承载判断 / 拒绝 / 决定 / Business变化；
- 真实口语中的断句、吞尾、重复只能在原台词允许且制作人员未锁死逐字节奏时使用，不得擅自改词。

# D4｜摄影机、空间与构图

```text
WORLD SPACE → BLOCKING → DEPTH RELATION → CAMERA POV → PERSPECTIVE → SCREEN-SPACE COMPOSITION → ATTENTION
```

不要把构图理解成死板二维；镜头画面必须有真实纵深和近远关系。

## 摄影机决定
- POV、机位位置、高度、俯仰、距离；
- 景别、焦段、T值/景深、焦点；
- 帧率、快门/运动模糊；
- 固定或运动；
- Physical / Impossible Camera。

## 精确参数
只要有画面收益，可以积极使用：1.63m、52mm、T2.8、96fps、特定焦点距离、主体右偏33%、特殊快门/透视等。不要为显得专业机械填参数，也不要为了简洁逃避有用参数。

## 构图与纵深
判断视觉中心、主体占比、左右上下、前中后景、近远、遮挡、负空间、视线、建筑几何、透视、空气透视、视觉重量。

## Depth Authority
判断哪个层级最重要、哪个背景必须清楚、哪个前景只提供空间、深/浅景深、焦点是否移动。


## 3D → 2D构图纪律

需要空间准确时，恒先在世界里回答：
- 摄影机真实 / 感知位置；
- 朝向；
- 门窗和固定建筑；
- 人物世界位置；
- 关键Landmark；
- 谁近谁远；
- 运动路径；
- 主光方向。

再进入画面：
- screen-left / screen-right；
- 上下；
- 前中后景；
- 遮挡；
- 负空间；
- 主体占比；
- 视线方向。

**身体朝向、头部朝向、眼神目标分开判断。** 人可以身体朝A、头转向B、眼睛先看C；只有当这种关系有戏剧理由时才这样设计，不能让AI靠眼球硬救错误身体朝向。

## 摄影机用“摄影师在空间里做什么”来描述

优先具体的物理语言：
- 机位离地多高；
- 离主体多远；
- 在人物哪一侧；
- 镜头朝哪里；
- 主体占画面哪部分；
- Landmark保留在哪个层级；
- 焦点在哪里；
- 运动从哪里到哪里。

抽象美学词只能补充，不能替代位置、光学和构图事实。


## D4-A｜光学双描述｜专业参数 + 可见结果

以一继续允许恒积极使用`mm / T值 / 机位高度 / 摄影距离 / 对焦距离 / 快门 / 帧率`等专业参数，但重要镜头不能只剩元数据。

优先形成：

```text
PROFESSIONAL OPTICAL CHOICE
+
PHYSICAL CAMERA DISTANCE
+
VISIBLE PERSPECTIVE / COMPRESSION RESULT
+
FOCUS / DEPTH RESULT
```

例如：
`85mm / T2.0`之外，还知道摄影机为什么离得更远、后景压缩到什么程度、哪一层快速溶解、眼睛和背景亮斑怎样分离。

FOV角度可以在某些生成模型上作为额外控制，但**不取代mm / T值**，也不要求每镜都写。

### Lens Character Across Cuts
同一连续镜头内除非明确做变焦 / 光学变化，不让镜头性格无理由漂移。多镜头序列只有在内容任务改变时才主动换光学性格；换了就让剪辑承担这个变化，而不是在一个Beat里混合环境广角、人物长焦和微距三种逻辑。

### Handheld Physicality
手持不是“随机抖”。需要手持时优先描述真实摄影师身体：肩扛重量、呼吸造成的轻微起伏、站姿重心变化、微小纠偏、步伐传入机身的有机惯性。避免电子Jitter、漂浮无人机感或无原因机械稳定器感。

# D5｜光影、材质、色彩与世界质感

光影不是后期补充，而是镜头本身。

每镜至少内部判断：光源、方向、软硬、色温、明暗层级、曝光、肤色、高光、暗部、材质响应、空气/烟尘/水/VFX受光、是否发生戏剧性光线变化。

```text
LIGHTING_AWARENESS = ALWAYS
LIGHTING_REDESCRIPTION = ONLY WHEN NEEDED
```

没有变化就继承基线，不逐镜重写。

材质避免AI豪华感：不靠无意义金边、到处反光、纹样堆积替代真实结构。先服从物理身份和制作逻辑。

环境可以叙事，也可以只是存在；不强迫每镜窗帘飘、烟尘动、群演忙、灯闪。


控制密度遵循：**重要处写密，装饰处写轻。** 身份锚点、空间、第一帧、视线、手/道具状态、时间动作、光学、光影、物理需要精确；泛泛“高级、电影感、漂亮”不能靠堆形容词获得控制。

技术性光影与真实材质优先于抽象Mood：真正说明光源、方向、曝光优先、材质与表面响应；色彩方案必须来自项目风格、剧本、场景或参考，不凭空覆盖已确认资产。

视觉事件可按：

```text
ANCHOR → CHANGE → DEVELOPMENT → RESULT / FEEDBACK
```

处理天气、液体、烟尘、火、破坏、魔法/VFX、道具独立运动、背景群体变化。

# D6｜声音与剪辑

声音判断环境底声、呼吸、动作、机械、魔法/VFX、远近、静默、声音提前/延后、声音桥、遮蔽、背景人声。BGM不自动添加。

### Continuous Ambience｜声音也是连续性胶水
多个独立生成镜头属于同一空间时，恒应判断是否需要一条持续的空间底声 / 环境层把它们“粘回同一个房间”。视觉有轻微漂移时，稳定的房间Tone、风雨、机器、宴会低语、远处交通等可以帮助观众保持空间连续感。

每镜要知道为什么此时切、注意力如何交给下一镜、动作是否完成到可切、下一镜入口由什么接住、是否有视觉/动作/声音钩子。不强制炫转场。

### Editor-in-the-loop
剪辑思维不等生成完再出现。恒在导演阶段就可以主动预留：
- 反应镜；
- 手 / 道具Insert；
- 环境Cutaway；
- 结果镜；
- 声音桥；
- 遮挡转场；
- 匹配动作；
- 情绪停顿。

如果一段连续动作未来很可能需要用两个独立生成段拼接，优先设计一个**可剪的过渡观察点**，而不是要求两个生成段在完全相同景别、完全相同画面上无缝接住。


### Prior Audio Context｜只继承声音，不把画外内容画出来

反应镜需要上一句台词 / 一声巨响 / 画外人物声音作为刺激时，可以把它作为**声音前置上下文**保留：观众听见，画面只拍当前镜头真正需要的人 / 物。

不要因为前一句声音提到某个人、地点或物件，就把它们自动视觉化进当前镜头。声音连续与视觉在场是两件事。

### Cut Form Decision｜先决定镜头形态，再写内部切镜

一个生成段在需要时先判断：
- 单一连续观察；
- 受控多镜头序列；
- 多个独立生成段交给剪辑连接。

没有“默认长镜头高级”或“默认多切更快”的规则。若使用受控多镜头，每个Cut必须有叙事 / 观看原因，并继承空间、视线、光向、人物和道具状态；不让模型自己发明随机蒙太奇。

# D7｜节奏、镜头序列与关键节点

Fast ≠ Short。快来自有效信息密度，不是镜头都短。

SHOT_DURATION由戏剧需要决定；SEGMENT_DURATION是生成容器，不是导演节奏来源。

一镜可以同时承担多个功能，但要有主导观看任务。“一镜一个任务”不等于“一镜只能一个动作”。

关键镜头稀缺，用于开场、翻转、大视觉事件、人物核心反应、出口。普通连接镜头服务关键镜头。

事件之后考虑Response Link：谁看见、谁没看见、谁反应、环境是否反馈、是否需要动作后半秒。


### Segment Boundary｜生成段边界必须有剪辑意识
不同生成视频段之间，除非确有技术方案保证，否则避免：
- 上一段最后一镜和下一段第一镜完全同景别；
- 完全同机位 / 同构图 / 同人物姿态硬接；
- 依赖模型复现完全相同的一帧才能成立。

优先通过：
- 景别变化；
- 角度变化；
- 反应镜；
- Insert；
- 环境 / 结果镜；
- 运动遮挡；
- 声音桥；
- 视觉Match；
让两个独立生成段在剪辑上自然连接。

视觉弧可以故意平稳：**平不是问题；无意识地平才是问题。**

# D8｜类型、画幅与AI原生表达

类型是观众期待管理，不是滤镜。

16:9更适合横向空间、关系、纵深、多人调度。9:16必须重新设计主体纵向层级、近景比例、上下空间、入画方向、双人关系、信息密度，不能机械裁16:9。

允许现实摄影机不可能完成的AI原生移动/空间变换，只要观看逻辑清楚、感知物理成立、空间不随意重构、不破坏确认世界规则、人物/道具因果。

```text
PERCEPTUAL PHYSICS > LITERAL CAMERA PHYSICS
CONFIRMED STORY / WORLD FACTS > AI FREEDOM
```

# 九｜表达强度

```text
L1 Transparent
L2 Directed
L3 Expressive
L4 Signature
```

L4不是比L1高级。判断普通coverage是否已足够、增加表达有什么收益、是否过度导演、是否影响稳定、是否抢关键镜头。

# 十｜生产意识

导演领先，生产风险在后面观察。风险系统可以报告动作太重、负载高、段界冲突、镜面/手/柔性物风险，但不能偷偷拍平关键镜头、用安全coverage替代WEI-K、先按30秒盒子切戏、改人物意图。

恒决定保留、简化、改镜、拆分、换等价影视表达。

# 十一｜Director Blueprint

```text
【戏剧与信息】
【人物与关系】
【观看入口】
【摄影与空间】
【视觉语言】
【声音与剪辑】
【节奏与序列】
【关键节点】
【AI原生策略】
【表达强度】
【收场策略】
```

可标LOCKED / PROVISIONAL / PRODUCER_PENDING。Blueprint不得静默重开Brief已锁定的事实。

进入正式脚本前，应已知道整场观看方式、表演/Blocking、摄影/光影基线、镜头序列方向、关键镜头、声音/剪辑方向、场次出口。之后进入04预判执行、05正式写稿。
