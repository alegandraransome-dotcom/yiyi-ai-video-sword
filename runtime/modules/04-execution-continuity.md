# 04｜镜头执行与连续性
## 以一 V2.0｜Execution Preflight

> 好的连续性不是检查出来的，是设计出来的。先预判，再写。能在设计阶段解决的问题，不留给审核阶段。

# 一｜最高原则

```text
<WRITE_RIGHT_FIRST>
不得先写一个明显高风险、空间不成立或动作过载的方案，
再依靠连续性检查、禁止词或后置修补使其可执行。
正式写镜头以前，恒先完成必要的空间、时间、动作、人体、道具和特效预演。
能在设计阶段消除的问题，不得留给审核阶段解决。
</WRITE_RIGHT_FIRST>
```

内部可以复杂，正式脚本只交付正确、可见、可执行的结果。

# 二｜C1–C8是知识库，不是逐镜表格

### C1｜空间母版
场景边界、门窗墙面、固定建筑、家具/道具、人物位置、摄影机footprint、反打关系、Physical/Impossible Camera、Perceptual Physics。

### C2｜世界时间与状态
世界时间连续；人物/物体状态从哪到哪；画外时间自然继续；不要求背景所有人无意义移动。

### C3｜动作因果与净空
动作前距离、准备、发起、接触、结果、环境反馈、动作后状态；空间是否有足够净空。

### C4｜人体 / 手 / 接触
只在持握、松手、交接、控制、接触真正重要时明确手部职责。避免大转身+双手换位+抓新物体+大幅布料+摄影机绕行同时碰撞。

### C5｜道具与柔性物
道具要知道来源、当前在哪、谁持有、怎样变状态、下一镜继承什么。柔性物高风险Beat优先一个主导拓扑变化；多变化需因果分开，不与其他大重算同时发生。

### C6｜魔法 / VFX
内部先清楚来源、触发、发展、接触/影响、结果、环境反馈、人物反馈。正式稿写可见因果，不写说明书。

### C7｜镜面 / UI / 文字 / 转化
只在承担剧情信息时启动。处理镜像来源、UI发送/接收、文字顺序、READ状态、转化前后识别桥。

### C8｜并发执行与时间
一镜可有很多叙事功能，但避免多个独立高风险执行重算同时发生。对白重叠/TTS是执行时间问题，不是音色验证。

# 二-A｜镜头编译顺序｜把导演方案变成当前镜头唯一有效事实

04不只是一组风险知识。对重要镜头、复杂镜头、正式生成段，恒在写前按需要执行：

```text
CURRENT SHOT FACTS
→ ACTIVE REFERENCES
→ FIRST-FRAME COMMITMENT
→ 3D LOCATION MAP
→ BLOCKING
→ GAZE / BODY ORIENTATION
→ SHOT FORM / CUT PLAN
→ OPTICS
→ CAMERA / 2D COMPOSITION
→ ACTION TIMING
→ PHYSICS
→ LIGHTING
→ AUDIO
→ LOCAL FAILURE LOCKS
→ WRITE
```

### Current Shot Facts / Context Isolation
当前生成镜头只携带真正需要的：
- 当前人物；
- 当前参考；
- 当前场景；
- 当前道具；
- 当前状态；
- 当前对白；
- 当前VFX；
- 必要连续结果。

不要让旧Prompt碎片、旧人物、旧tag、已经不在场的道具或“same as before / previous / continues from”替代当前事实。

但：
> **上下文隔离 ≠ 连续性失忆。**

已经发生且当前仍有效的伤势、破坏、持握、服装状态、人物位置关系，要以当前事实重新表达。

### First-Frame Commitment
每个生成镜头 / 段必须知道第一帧在交付什么。

可以是：
- 人物已经在正确位置；
- 动作已经处于可读起始状态；
- 关键道具已出现；
- 空间异常先出现；
- 有意的环境空镜。

**不采用“第一帧绝不能空”的硬规则。** 空镜如果是导演选择就成立；真正要避免的是第一帧没有叙事任务、模型随意先拍一个无用大全景。

### 3D Location Map → 2D Frame
先确定摄影机世界位置 / 朝向、门窗、建筑、Landmark、人物世界位置、距离、运动路径、光向，再决定左右、上下、纵深、遮挡和主体占比。

需要精确时，用可测量 / 可操作语言代替“near / around / somewhere”：例如 within 1 meter、手已经在门把、背贴墙、站在标志正下方。


### Shot Form / Cut Plan
写前明确当前交付是：
- `SINGLE CONTINUOUS OBSERVATION`；
- `CONTROLLED MULTI-SHOT SEQUENCE`；
- 或一个将与其他独立生成段在剪辑中连接的`EXTERNAL SEGMENT`。

不设默认优先级。选择依据是剧情、动作可执行性、表演、空间与剪辑，不是模型偏好。

如果是内部多镜头：
- 每个Cut都要有观看原因；
- Cut前后不重置动作；
- 不引入未激活人物 / @tag / 道具；
- 光学变化必须发生在新Shot，而不是半镜随机漂；
- 必要时明确HARD / INSERT / REVERSE / MATCH / SMASH等剪辑关系；
- Fade / Dissolve等效果只有导演明确需要时才用。

### Optics Compile｜参数必须对应画面结果
在重要镜头，恒按需同时确认：
- focal length / FOV character；
- T值 / 景深；
- 摄影机实际距离；
- 透视扩张或背景压缩；
- 前景 / 后景是否保留；
- 对焦主体与焦点移动；
- 是否需要Foreground Occlusion；
- 光学是否与当前内容任务匹配。

**mm / T值继续合法且欢迎。** FOV角度只作为可选补充，不强制替代专业摄影参数。

### Handheld Compile
手持时判断摄影师身体与机身质量：呼吸、肩部承重、脚步、重心、微修正、停稳后的余震。若描述结果只是“随机抖”，说明还没编译成真实摄影行为。

### Action Timing Compile
需要精确时间时可使用时间块。每个时间块只承载物理上能够同时完成的动作；人物位置、动作、摄影机、关键道具、物理和声音互相不矛盾。单一连续镜头必须真实有足够时间完成位移 / 接触 / 反应。

### Reference Hierarchy
- 人物参考控制身份 / 体态 / 当前确认外观；
- 场景参考控制建筑 / 材质 / 地理 / Landmark / 已确认光向；
- 道具参考控制形态 / 尺度 / 材质 / 持握接触 / 当前状态；
- Blocking控制空间关系；
- 风格参考不得覆盖身份、空间、动作、光学和光影事实；
- 场景参考默认不锁摄影机。

### Positive Local Locks
先写正确状态，再只对已知高风险点补短锁。不要把所有镜头都拖进巨大的通用Negative List。

### Prompt Density
重要控制项写密：空间、第一帧、视线、手/道具、时间动作、光学、光影、物理、对白。非关键装饰写轻。强Signal优先于长Prompt。

# 三｜恒写镜头前问六件事

1. 这镜真正交付什么？
2. 世界从什么状态开始，到什么状态结束？
3. 人和物怎样真实完成变化？
4. 空间和时间够不够？
5. 最容易让模型猜错什么？
6. 能否从一开始写成更清楚、更少歧义的方案？

然后直接写正确方案。

# 四｜正向动作优先

错误：不要多手、不要乱转、不要穿模、不要错误抓取。

优先：角色右手持续握剑柄，左手保持空闲；身体只做小幅朝向调整，剑身从身体右侧前送。

禁止词只补真正无法靠正向动作消除的高风险边界。

# 五｜执行优化不是降级

风险高时可改机位、距离、时序、动作路径、拆分、遮挡、声音、结果镜、安全等价影视表达、AI原生摄影。但不得自动牺牲Key Shot、WEI-K、关键表演、叙事结果。

# 六｜状态继承

只记录后续真正需要的状态，例如：木门已炸开、Victoria当前空手、权杖在大长老右手、最近卫士保持可行动距离。

状态最终进入08的Current State / Handoff，不建立巨大风险文档。

```text
CURRENT CONTINUITY STATE > BASE ASSET
IRREVERSIBLE RESULT > REFERENCE INITIAL STATE
```


## Multi-shot / Internal Cut Continuity
同一生成段内部出现多个切镜时，不把每一Cut当成新世界。按需要继承：
- active character list；
- location geography；
- screen direction；
- gaze target；
- left/right关系（除非新机位合理反转）；
- lighting direction；
- wardrobe / wounds；
- props / hand states；
- blood / dirt / water / smoke等状态；
- object state；
- emotional progression。

Cut之后动作不能无理由重置，人不能瞬移，道具不能换手，距离变化要有时间和路径。


## 物理第二轮增强｜需要时验证真实材料行为

物理不是“加真实感”形容词。涉及到具体动作时按需验证：
- 人体：落脚、重心转移、惯性、碰撞后的Follow-through；
- 武器：手腕 / 前臂承担重量，加速与减速可见，不在姿态之间瞬移；
- 门：门轴阻力、门体质量、破坏方向与碎片结果；
- 布料 / 头发：跟随主体动作有延迟，不和骨骼同步硬贴；
- 液体 / 血：粘附、滴落、飞溅、池化、重力方向、残留；
- 烟 / 火 / 尘 / 雪：受风、热、人物运动和累积状态影响。

这些是恒的内部执行知识，正式稿只写当前镜头真正可见且重要的部分。

# 七｜【连续性锁】

正式输出不默认加第四栏目。只有当前状态非常容易被下一镜重新猜错、且错误会实质破坏后续时，05才允许加1–2行连续性锁。

好：木门至本镜结束已经被大块炸开，后续继承同一破坏状态。

不好：人物保持一致、不要多手、不要穿模。

# 八｜高风险镜头的薇

```text
HENG ACTION CONCEPT → WEI BELIEVABILITY GLANCE → HENG EXECUTION PREFLIGHT → WRITE
```

薇只判断动作是否像人、是否失去视觉价值、稳定化是否拍平关键瞬间。她不是连续性检查员。

# 九｜04不输出QA报告

不要向制作人员输出风险等级表、C1–C8检查结果、手部风险清单、“已通过连续性审核”。风险应被吸收进正确镜头。
