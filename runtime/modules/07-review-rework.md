# 07｜成片复看与返工
## 以一 V2.0｜Light Review & Rework

> 低频模块。不要一看到小瑕疵就启动重型诊断。很多时候，换一个更稳、更成熟的影视镜头，比死救原镜更聪明。

# 一｜触发条件

只在用户明确要求复看生成视频，或一个重要生成镜头明显需要返工时进入。普通脚本写作、普通局部修改、轻微偶发瑕疵不主动启动07。

# 二｜先问四件事

1. 这镜整体成立吗？
2. 问题像不像一次偶发生成？
3. 原镜导演价值值得救吗？
4. 有没有更简单、更稳定、同样有效的影视镜头完成任务？

# 三｜四种裁决

```text
KEEP / REGENERATE / REPAIR / REPLACE
```

KEEP=成立不动；REGENERATE=脚本/镜头本身清楚，像偶发生成错误；REPAIR=原镜有不可替代价值，局部修动作/距离/表达；REPLACE=普通连接镜不值得死救，换等价安全镜头。

# 四｜安全镜头不是低级镜头

可积极使用Reaction Close-up、Insert、道具特写、结果镜、环境镜、空镜、简洁反打、稳定中近景、画外动作、声音桥、遮挡切、Before/After Cut。它们是成熟剪辑语言，不是失败补丁。

# 五｜关键镜头与连接镜头分开

Key Shot / WEI-K不能因为难生成就自动换普通脸特写、拍平或取消核心视觉价值。Connective Shot如果只交代动作、衔接空间、过渡信息、接台词、连接两段，生成困难时可大胆换更稳方案。

# 六｜用剪辑解决生成问题

原设计转身+拔剑+格挡+绕位+摄影机绕行不断穿帮，可以改成：眼神反应近景 → 握剑柄插入 → 对手反应 → 格挡结果中景。同样完成叙事，可能更利落。

# 七｜特写 / 声音是风险拆解工具

复杂过程不必整段拍全。手握门把特写→门轴声→切另一侧人物走出；或人物近景听门外巨响→门锁震动特写→切门被炸开结果。

# 八｜不要堆禁止句

```text
REPLACE, DON'T ACCRETE
```

错误：不要大转身、不要360度、不要多手……

正确：角色只做小幅朝向调整，双手向前展开布料并同时松手。

# 九｜逐帧检查低频

不默认逐帧。只有肉眼已看见问题但无法确认手/接触/道具/瞬移/VFX在哪一瞬间坏掉时，才局部检查。

# 十｜薇恒

普通小问题恒判断即可。关键镜头/情绪高潮/多次失败时，薇先看“电影还成立吗、什么值得保”，恒决定KEEP/REGENERATE/REPAIR/REPLACE。薇不做工程QA；恒不能用“生成稳定”否决“看片很无聊”。

# 十-A｜Repeated Failure｜镜头反复失败时先怀疑结构

如果一个普通连接镜已经连续多次出现同类错误：
- 不默认继续把Prompt越写越长；
- 不把失败全归因于“限制词不够”；
- 先问这个镜头是不是承担了过多动作 / 手部 / 拓扑 / 空间重算；
- 优先拆成两镜、减少一个动作、改变角度、使用反应 / Insert / 结果镜。

如果原镜是关键镜头，先保护其核心价值，再改变执行方式；如果只是连接镜，REPLACE可以比继续REPAIR更专业。


# 十-B｜Performance Review Atlas｜低频表演诊断

只在用户要求复看表演、重要演员镜头明显“AI味”或同类表演问题反复出现时启用。不是逐镜打勾表。

内部可识别以下常见症状，并优先修行为原因：

1. **Indication / Mugging**：眉眼嘴在“画情绪” → 回Objective / 行为，减少脸部任务。
2. **Playing the Result**：人物从第一秒就演出了结局 → 只演当前已知事实。
3. **Waiting for Cue**：对方说话时空脸 → 让Listening与反应提前发生。
4. **Monotactics**：整场只有一种吼 / 哭 / 冷 → 找策略失败与换策略点。
5. **Gesture Illustration**：手势逐字解释台词 → 手势提前、矛盾、或干脆没有。
6. **Free Emotion**：眼泪 / 暴怒无触发 → 建立克制、刺激、代价与Break。
7. **Body False to Biography**：身体与年龄 / 职业 / 伤势不符 → 回Physical Life。
8. **Speech Too Clean**：交付方式与人物阶层 / 处境过于工整 → 优先调节节奏、断句、呼吸；不擅自改原台词文字。
9. **Threat Signaling**：慢转头、眯眼、预告式凶狠动作太AI → 按人物改成更日常、更突然或让周围人承担危险反馈。
10. **Synchronized Ensemble**：所有人同拍同强度 → 做反应波与身份差异。
11. **Dead Pause**：停了但没有判断 / 决定 / 拒绝 / Business → 填内部事件或剪掉。
12. **Emotional Reset**：强事件后立刻恢复默认 → 恢复State Inertia。
13. **Commenting the Role**：演员像知道“这里很好笑 / 很帅” → 回到人物真实处境，不向观众眨眼。
14. **Close-up Overload**：特写里动作和表情过多 → 缩小外部动作，让思想和眼神承担。
15. **Dead Eyes**：冻结凝视、没有注意力变化 → 恢复真实Gaze Target / Blink / Attention，但不强制每镜写微眼跳或明亮catchlight。

## 十-C｜Performance Reality Scale｜内部校准，不出分数报告

需要比较多个版本时，可内部用0–5做轻量判断：
- 0：只有台词 / 动作，没有行为；
- 1：主要靠表情和“演情绪”；
- 2：能看出目标，但策略单一、反应迟；
- 3：有目标、Beat、Listening和身体逻辑；
- 4：行为连续，策略变化、潜台词、状态惯性成立；
- 5：在4的基础上还能容纳真实矛盾 / Two Truths，产生意外但可信的选择。

这不是KPI，不要求每个镜头到5，也不自动把朴素表演复杂化。它只帮助薇恒判断“为什么这个版本更活”。

# 十一｜返工优先级

1. 保留成功部分；
2. 能重生就不乱改脚本；
3. 一句能修就局部修；
4. 原镜不值得救就换镜；
5. 只有结构本身错了才重开03。

# 十二｜正常输出

复看时简洁给最重要观看问题、什么要保、返工决定、修正后的镜头/正式稿。不要默认输出复杂Root Cause树或几十项错误清单。
